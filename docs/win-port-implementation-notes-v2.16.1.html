Deviations

  • D3 delivery = PTY argv, not a typed -c flag (2026-09-04). Plan §6.5's typed -c 'notify=["node","script"]' is not byte-exact through PowerShell 5.1 (inner quotes stripped; Program Files splits) and --% cannot precede cron/整理 prompts. Conservative choice that still turns notify on: FanBox-launched Codex (one-click, resume, cron, AI 整理) is pty.spawn'd with a real argv from buildCodexSpawnSpec (npm shim → node.exe + JS entry, or Electron-as-node). -c and notify=["…","…"] are two slots; the prompt is another. codexHooksFlag / winCodexHooksFlag still return '' so nothing types the JSON into a shell. writeHookFiles writes codex-notify.js. Hand-typed codex stays un-hooked (C11). An argv-spawned tab is tracked in termAgentKind so quit/stay-awake treat it as an agent until notify facts arrive or the process exits.
  • §6.2 activeAgentTerms Windows arm refined (2026-09-04, Gate C). The plan's arm ("un-hooked tabs count as active") contradicts tests A3/C6: every FanBox window has a bare PowerShell tab, so Quit always asked ("还有 1 个 agent 正在干活") and the stay-awake dot never went off. The "unknown = busy" rule is kept but fed by the existing child-process probe cache: winProbeKids(pid) (fresh ≤ 10 s) → no children = idle; children, or a stale/failed probe = active. before-quit refreshes a stale cache and re-enters quit; the 30 s lid poll refreshes first; ✕ / Alt+F4 on Windows route through the same confirmation instead of killing terminals silently. Verified in the hooks campaign: quit mid-turn asks and names claude, cancel keeps everything; quit with only idle shells exits without a dialog.
  • Hooks flag only when the file exists. The CHANGELOG claimed it; the renderer did not check. Added env:hooksReady (main, sendSync) → fanboxEnv.hooksReady; winClaudeHooksFlag() returns '' without it. env:nodeExe removed together with the Codex flag.
  • Test infrastructure only: matrix/launch.js ROOT / fake home / tools PATH are overridable by FANBOX_MATRIX_ROOT / FANBOX_MATRIX_HOME / FANBOX_MATRIX_TOOLS (defaults unchanged); matrix/setup-fixtures.js recreates the per-run fixtures the phases recycle. Phase expectations updated for 2.16.1: cron claude now carries --settings (phase3f), upstream's mdHtml fails closed as escaped text without a <pre> wrapper (phase3i), drive letter / home derived from the launcher (phase2/3a/3h). D6 editor reload is checked on an .md file: external-edit reload is an md-editor feature upstream (Monaco code editors rely on the mtime conflict guard), identical on macOS. Playwright 1.49 page.evaluate accepts one argument after the function — C9 now passes { p, extra } as that object (first Gate C re-run threw "Too many arguments"; product code unchanged).
